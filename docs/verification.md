# Manual Verification Guide

**Author:** Nour El Houda Bouajila (https://github.com/nourhb)

You don't have to take the pipeline's word for it. Anyone can verify any
image produced by this project using only `cosign` — no cluster, no secrets.

Prerequisites: `cosign` v2.x installed.

## 1. Verify the image signature

```bash
IMAGE="ghcr.io/nourhb/zero-trust-supply-chain/demo-app@sha256:<digest>"

cosign verify \
  --certificate-identity "https://github.com/nourhb/zero-trust-supply-chain/.github/workflows/supply-chain.yaml@refs/heads/main" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  "$IMAGE"
```

What this proves:
- The image was signed with a Fulcio certificate chaining to the Sigstore root.
- The certificate was issued to **this repo's workflow on `main`** — not just
  "someone with a GitHub account".
- The signature is recorded in the **Rekor transparency log** (Cosign checks
  this by default; a signature missing from Rekor fails verification).

## 2. Verify the SLSA provenance attestation

```bash
cosign verify-attestation \
  --type slsaprovenance \
  --certificate-identity "https://github.com/nourhb/zero-trust-supply-chain/.github/workflows/supply-chain.yaml@refs/heads/main" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  "$IMAGE"
```

This returns the signed provenance statement: source repository, commit SHA,
and builder identity (`github-hosted` runners). It answers *"how was this
built?"* — a signature alone only answers *"who signed it?"*.

## 3. Verify the SBOM attestation

```bash
cosign verify-attestation \
  --type spdxjson \
  --certificate-identity "https://github.com/nourhb/zero-trust-supply-chain/.github/workflows/supply-chain.yaml@refs/heads/main" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  "$IMAGE"
```

This proves the signed software bill of materials (SPDX, generated by Syft)
is bound to this exact digest — the dependency list cannot be swapped
after the fact.

## 4. Inspect the transparency log entry (optional)

```bash
# Show the Rekor entry for the signature:
cosign verify "$IMAGE" \
  --certificate-identity "https://github.com/nourhb/zero-trust-supply-chain/.github/workflows/supply-chain.yaml@refs/heads/main" \
  --certificate-oidc-issuer "https://token.actions.githubusercontent.com" \
  --output-text 2>&1 | head -20
```

Or use the one-shot helper:

```bash
./scripts/verify.sh "$IMAGE"
```

## What a failure looks like

- **Unsigned image** → `Error: no matching signatures` — the image was never
  through this pipeline (or was tampered with after signing).
- **Wrong identity** → certificate subject mismatch — signed by *someone*,
  but not by this repo's workflow.
- **Missing from Rekor** → transparency check fails — treat as untrusted.

Any of these means: **do not run this image**.
